Fiesta Restaurant 🍽️
Demo Website for a Restaurant to Enable Online Ordering

Fiesta Restaurant is a responsive and user-friendly demo website designed to showcase a restaurant's menu and facilitate online ordering. Built using HTML and CSS, this project serves as a foundational template for restaurants aiming to establish an online presence.

🌐 Live Demo
Experience the live version of the website here:
👉 vinodhariharan.github.io/Fiesta-Restaurant

📁 Project Structure
The project comprises the following key files and directories:

index.html: Homepage featuring the restaurant's branding and navigation.

about.html: Section detailing the restaurant's story and values.

menu.html: Comprehensive list of available dishes and beverages.

order.html: Interactive form allowing customers to place orders online.

signup.html: User registration page for account creation.

thank.html: Confirmation page displayed post successful order placement.

menu.css: Styling specific to the menu page.

signup.css: Styling specific to the signup page.

images/: Directory containing visual assets like logos and dish images.

🚀 Features
Responsive Design: Ensures optimal viewing across devices.

User-Friendly Navigation: Intuitive layout for seamless user experience.

Online Ordering: Functional order form to simulate real-time ordering.

Account Registration: Signup page for new users.

Visual Appeal: Incorporation of images to enhance user engagement.

🛠️ Technologies Used
HTML5: Structuring the content and layout.

CSS3: Styling and responsive design.
